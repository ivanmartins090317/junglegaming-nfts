# Kurio

Esqueleto da prova frontend. Ainda sem tela.

## Abrir

```bash
pnpm install
pnpm dev
```

O mock sobe ligado. Para abrir sem ele, no PowerShell:

```powershell
$env:VITE_ENABLE_MOCK="false"; pnpm dev
```

A mesma chave pode ir num `.env` local, copiado de `.env.example`. O `.env` não entra no Git.
