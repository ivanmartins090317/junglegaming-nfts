# Specs

Índice vivo das specs. Um arquivo por feature em `docs/specs/`.

| Data | Slug | Tipo | Status | Spec |
| --- | --- | --- | --- | --- |
| YYYY-MM-DD | slug | `feature` ou `lite` | `draft` | [spec](YYYY-MM-DD-slug.md) |

Status: `draft` → `aprovada` → `em_implementacao` → `done`.

Spec aprovada não muda sem pedido explícito. O índice só acompanha o status.
